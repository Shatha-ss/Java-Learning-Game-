# Java-Learning-Game-
## Project Description 
A small reusable game engine that generates interactive, playable challenges to help learners practice core Java programming concepts.

## Current proposed system idea
Our proposed system is a reusable game-based platform for creating and verifying playable Java programming challenges. Students write Java code to control game objects and complete challenges related to basic Java concepts such as loops, conditions, variables, and arrays. The system executes the code as visible game actions and automatically verifies the challenge and solution for correctness, solvability, and alignment with the intended Java concept. An LLM may later be integrated to generate new challenge configurations and learning content.
